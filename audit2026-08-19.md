## 2. Architecture Assessment

### What's Built & Working

**Rust core** — 8 crates fully functional:
- `aether_orchestrator` — Conversational AI pipeline (intent routing, dual-GPU Ollama, Kokoro TTS, Whisper STT, gRPC file search, skills)
- `aether_audio` — Mic capture, VAD, wake word, spatial mixer (binaural HRTF), output
- `aether_ide` — Tree-sitter (6 langs), LSP client (12 tests), DAP client (18 tests), project indexer, cursor nav, text buffer, voice editor, JSON-RPC IPC (50+ methods)
- `aetherfs-core` — File indexing daemon (SQLite FTS5 + Qdrant + BLAKE3)
- Plus `aether_browser`, `aether_buffer`, `aether_attention`, `aetherfs-cli`

**Python layer** — 15+ modules for voice UI: main daemon, intent router, audio engine, browser, email, file browser, IDE, docs, ebook, screen reader, settings, skills, earcons
